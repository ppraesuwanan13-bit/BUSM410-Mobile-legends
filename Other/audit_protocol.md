# Project Audit

- As we work, write our process for checking your work in Other/audit_protocol.md. When a check shows a new habit worth keeping, add it there. Show us each addition before you save it.
- When we check, question, or correct your work in a way worth logging, flag it: show us the proposed entry for Other/audit_log.md and add it only after we approve.
- Propose only substantial checks (ones that caught a mistake, required a source, or changed our analysis), so the log stays relatively short. Skip routine approvals.
- Use the same table columns for every entry in Other/audit_log.md. Never invent a check we didn't do.
- File each entry under one category heading: Caught an error, Verified a claim, Separated fact from opinion, Changed the analysis, or Improved the agent's instructions. Keep a summary table at the top with each category, its entry count, and a link to its section.
